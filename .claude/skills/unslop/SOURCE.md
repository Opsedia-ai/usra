## How Usra uses it

- Usra is Flutter, while unslop is written for web code. Use its audit (`references/signs.md`) and its nine passes as a review of Flutter screens and of the HTML design canvas (`design/app-screens`).
- Usra's accepted design and tokens (`app/lib/core/design/tokens.dart`, `design/app-screens/tokens.json`) are the brand. Run unslop in polish mode: fix what the audit finds, and don't invent a new direction.
- Don't generate images through paid services without the founder's yes, and don't run the story-video script unless asked.
